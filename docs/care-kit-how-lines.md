# Care Kit — "How" Lines (Draft for Review)

**Status:** draft, not in Airtable, not in the app. Nothing reads this file yet.

One short, plain instruction per recommendation. It replaces the full description on the care kit card; the description moves behind a "Why this helps" tap.

**The brief:** not too colorful, clear enough that it actually helps. So: concrete, doable, no metaphors, no nervous-system explanations, no exclamation points.

**Length:** 8–13 words, average 10.7. The descriptions they replace average 32.

**How to review:** edit the right-hand column directly. Anything you change here is what gets loaded into a new `how` column in Airtable.
